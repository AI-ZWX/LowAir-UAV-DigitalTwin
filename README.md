# 章伟熙 · 低空数字孪生模拟系统

> UE5 + Cesium for Unreal · 无人机监管 · 预测预警 · 2026

## 👤 我在做什么

UE5 写实场景 5 年，2026 年转低空经济方向。正在从零搭建一套**低空无人机数字孪生模拟系统**（L4TwinSlice），覆盖实时遥测、TTC/TTE 预测预警、电子围栏、事件闭环处置、三维可视化全链路。

这是一个正在建设中的项目。仓库记录架构决策、踩坑排查和技术拆解——不是教程，是真实开发过程。

## 🛠 技术栈

| 层级 | 技术 |
|------|------|
| 引擎 | Unreal Engine 5.7 / C++ / Blueprint |
| 地球引擎 | Cesium for Unreal / 3D Tiles / WGS84-ECEF坐标转换 |
| 通信 | WebSocket / Node.js 网关 |
| UI | UMG / 信息架构 / 颜色语义系统 |
| 模拟 | 遥测数据模拟器 / 多机并发 / 围栏规则引擎 |
| 方向 | 低空经济 / 无人机监管 / 数字孪生 |

## 📂 系统能力

- **实时态势**：多机遥测接入、三维地球可视化、按对象聚焦
- **预测预警**：TTC（碰撞时间）/ TTE（围栏侵入时间）推演，分层架构——UE端逐帧外推、网关端阈值判定
- **事件闭环**：围栏侵入→预测→告警→处置→回执→验证
- **视觉系统**：11+ 色语义编码、状态符号双通道、光照管线统一治理
- **架构决策**：5 篇 ADR 覆盖渲染方案、通信协议、数据存储、部署策略
