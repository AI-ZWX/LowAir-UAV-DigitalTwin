## 📂 项目：L4TwinSlice 低空无人机数字孪生管控平台

一个面向城市级低空监管的桌面端数字孪生系统。核心能力：

- **实时态势感知**：多机遥测接入、三维地球可视化、按对象聚焦
- **事前预测预警**：TTC（碰撞时间）/ TTE（围栏侵入时间）推演引擎，分层架构（UE端逐帧外推 + 网关端阈值判定）
- **事件闭环处置**：围栏侵入→预测→告警→处置→回执→验证完整链路
- **架构决策记录**：5 篇 ADR 覆盖渲染方案、通信协议、数据存储、部署策略
- **视觉系统**：11+ 色语义编码、状态符号双通道、Lit/Unlit 兼容、光照管线统一治理
