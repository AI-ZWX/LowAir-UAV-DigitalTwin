# 低空数字孪生——模拟现实，解决问题

> 不是在搭 Demo。是在模拟真实场景中数字孪生工程师会遇到的问题，然后一个一个解决。

## 我在做什么

低空无人机监管场景下，数字孪生系统会遇到哪些问题？我把它们模拟出来，动手解决，记录全过程。

不是教程，不是"最佳实践"——是**问题→尝试→失败→找到根因→解决→提炼教训**的完整链路。每个问题都是现实场景中会真实发生的。

## 已经模拟并解决的问题

### 视觉层

- **[改一个颜色，炸了四个地方](./articles/2026-09-02-颜色撞色三轮排查.md)** — 场景里 11+ 种颜色共存，每改一种颜色会连锁撞色。HDR 色值≠渲染值。颜色通道饱和后的正解是符号+颜色双通道编码。

- **场景过曝发白**（待整理） — GameMode 强制把所有后期体设为 Unbound，多个光照源互相叠加。根因不是曝光参数，是光照控制权分散。

- **围栏在 Lit 模式下消失**（待整理） — UNLIT 材质化没错，但 Python MaterialEditingLibrary 改节点时 Emissive 链被拆断，材质输出为 0→全透明。教训：Python 改材质在本环境不可靠，需三重验证。

- **状态符号系统**（待整理） — 接近预警用颜色区分撞色→改符号+颜色双通道→机身效果从亮度摆动迭代到红白 4Hz 急闪。核心原则：常亮=状态，急闪=预警中。

### 架构层

- **[为什么选 UE5 不选 Three.js](./articles/UE5-vs-WebGL-架构决策.md)**（待发布） — 5 篇 ADR 记录的架构决策，涵盖渲染方案、通信协议、数据存储。

- **TTC/TTE 预测预警分层设计**（待发布） — UE 端逐帧外推（60fps 交互体验）+ 网关端阈值判定（数据一致性）+ 可下沉边缘节点。演示级和生产级的边界在哪。

- **UE+UMG 同屏一体 vs Web+Pixel Streaming**（待发布） — 双端架构的投入产出评估，在未确认硬件/资产条件时不承诺非示范效果。

待业期间，没有真实设备、没有真实飞控、没有倾斜摄影数据。但我可以模拟这些条件缺失时数字孪生系统会遇到的问题，然后解决它们。

等到真的有设备和数据那天，我已经把能提前踩的坑踩完了。
